# Flujo de Experiencia Docente - AprendeLocal

## El problema actual

El flujo actual es: Mapa → Punto → Proyecto
Pero un docente NO piensa en puntos geográficos primero.

Un docente piensa:
- "Tengo que enseñar el OA 3 de Ciencias de 6to"
- "¿Qué puedo hacer con mis estudiantes esta semana?"
- "Quiero algo que los saque de la sala"

## Modelo de datos: Objetivos de Aprendizaje

Para que esto funcione, necesitamos una tabla de OA del currículo chileno:

```
curriculum_objectives
├── id
├── code          → "OA1_CN_6"
├── subject       → "ciencias_naturales"
├── level         → "6to_basico"
├── description   → "Explicar, a partir de una investigación..."
├── axis          → "Ciencias de la vida"
└── keywords      → ["fotosíntesis", "plantas", "luz", "agua"]
```

Y una tabla de relación con proyectos:

```
project_curriculum_alignment
├── project_id    → FK stem_projects
├── objective_id  → FK curriculum_objectives
└── coverage      → "principal" | "secundario"
```

Cuando Claude genera un proyecto, ya incluye los OA en `curriculum_alignment`.
Lo que falta es cruzar eso con una tabla real de OA para que el
Camino B funcione (buscar por currículo → encontrar proyectos).
